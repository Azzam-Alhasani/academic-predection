How the model was chosen

Instead of picking a model by habit, {{ study.classification.after_sem1.candidates|length }} candidate models were compared on {{ study.meta.n_students }} real students (dropout rate {{ '%.1f'|format(study.meta.dropout_rate * 100) }}%) with the same evaluation rules.

  1. Fair scoring. {{ study.meta.cv.splits }}-fold cross-validation repeated {{ study.meta.cv.repeats_stage_a }} times: every student is scored by a model that never saw them, and every model sees identical splits.
  2. Honest tuning. The strongest models were tuned with nested cross-validation: settings are chosen on training data only and scored on students the tuning never saw, so tuning cannot inflate the result.
  3. Is the difference real? Corrected paired t-tests (Nadeau & Bengio) compare each model with the best; p < 0.05 means "really worse", otherwise "tied".
  4. Decision rule. Highest mean ROC-AUC; if models are within one standard error, the simpler one wins.

Conclusions and limits
  • Target accuracy. The best models reach about {{ '%.0f'|format((study.classification.after_sem1.tuned|selectattr('key', 'equalto', study.classification.after_sem1.selected)|list)[0].metrics.accuracy.mean * 100) }}% after semester 1 and {{ '%.0f'|format((study.classification.after_sem2.tuned|selectattr('key', 'equalto', study.classification.after_sem2.selected)|list)[0].metrics.accuracy.mean * 100) }}% after semester 2, against {{ '%.0f'|format((study.classification.after_sem1.candidates|selectattr('key', 'equalto', 'majority')|list)[0].metrics.accuracy.mean * 100) }}% for a model that always says "stays".
  • The top models are statistically tied. Random forest, gradient boosting, logistic regression and the neural network differ by less than the noise (p-values above 0.05). Logistic regression is almost as good and fully explainable, which is why it is also used to show why a student is flagged.
  • The limit is the data, not the algorithm. Five very different model families agree, and the learning curve is flat. Better accuracy would need new information (attendance, assessment scores, engagement), not a fancier model.
  • Imbalance matters. About one student in three withdraws, so recall is reported next to accuracy: a model can look accurate and still miss many at-risk students.
  • Transfer. The data is from one Portuguese polytechnic. For UTAS, retrain on UTAS records with the same script before relying on the numbers.
