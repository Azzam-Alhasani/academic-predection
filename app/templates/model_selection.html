How the model was chosen

Instead of picking a model by habit, {{ study.classification.after_term1.candidates|length }} candidate models were compared on {{ study.meta.n_students }} real course records of {{ study.meta.n_people }} students (failure rate {{ '%.1f'|format(study.meta.fail_rate * 100) }}%; a student's courses are always kept on the same side of every test split) with the same evaluation rules.

  1. Fair scoring. {{ study.meta.cv.splits }}-fold cross-validation repeated {{ study.meta.cv.repeats_stage_a }} times: every student is scored by a model that never saw them, and every model sees identical splits.
  2. Honest tuning. The strongest models were tuned with nested cross-validation: settings are chosen on training data only and scored on students the tuning never saw, so tuning cannot inflate the result.
  3. Is the difference real? Corrected paired t-tests (Nadeau & Bengio) compare each model with the best; p < 0.05 means "really worse", otherwise "tied".
  4. Decision rule. Highest mean ROC-AUC; if models are within one standard error, the simpler one wins.

Conclusions and limits
{% set c1 = (study.classification.after_term1.tuned|selectattr('key', 'equalto', study.classification.after_term1.selected)|list)[0] %} {% set c2 = (study.classification.after_term2.tuned|selectattr('key', 'equalto', study.classification.after_term2.selected)|list)[0] %} {% set base = (study.classification.after_term1.candidates|selectattr('key', 'equalto', 'majority')|list)[0] %}
  • Target accuracy. The selected models reach about {{ '%.0f'|format(c1.metrics.accuracy.mean * 100) }}% after term 1 and {{ '%.0f'|format(c2.metrics.accuracy.mean * 100) }}% after term 2, against {{ '%.0f'|format(base.metrics.accuracy.mean * 100) }}% for a model that always says "passes". ROC-AUC is {{ pm(c1.metrics.roc_auc) }} and {{ pm(c2.metrics.roc_auc) }}.
  • Marks do the work. The permutation-importance charts show that the term marks carry almost all the signal. Absences and course add very little once the marks are known. Absences matter mostly at the extreme (11 or more) - see Analytics.
  • Several models are statistically tied. After term 2, logistic regression, gradient boosting and random forest are within noise of each other (p > 0.05), so the simplest (logistic regression, which can also explain a result) is chosen.
  • The limit is the data, not the algorithm. Different model families agree and the learning curve flattens. Higher accuracy would need new information (assessment scores, participation), not a fancier model.
  • Missed students. At the default 50% alert level about {{ '%.0f'|format((1 - c1.metrics.recall.mean) * 100) }}% of students who later fail are not flagged after term 1. Lowering the alert level to 40% flags more of them; the threshold table shows the trade-off.
  • Transfer. The data is from two Portuguese secondary-school courses, not UTAS. Retrain on UTAS records with the same script (python -m app.ml.model_selection) before relying on the numbers.
